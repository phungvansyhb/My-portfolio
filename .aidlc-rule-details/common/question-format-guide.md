# AI-DLC Common Rule: Question Format Guide

When clarifying requirements with the user:
- Present structured, high-impact questions grouped together rather than one-at-a-time chat back-and-forth.
- Provide clear options with a recommended default based on project context.
- Record all user answers and resulting decisions chronologically in `aidlc-docs/audit.md`.
- Proceed to Construction only after explicit user validation at the approval gate.
