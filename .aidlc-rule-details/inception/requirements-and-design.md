# AI-DLC Inception Rule: Requirements & Application Design

1. **Workspace Detection**: Inspect existing repository files, toolchain (`Node`, `npm`, `Next.js`), and git configuration.
2. **Requirements Analysis**: Capture functional scope, non-functional requirements (performance, accessibility, SEO, responsive layout), constraints, and success criteria in `aidlc-docs/inception/requirements.md`.
3. **Application Design**: Document routing, component boundaries (Server vs Client Components), data schema (`src/data/portfolio.json`), and Vercel ecosystem integrations in `aidlc-docs/inception/application-design.md`.
4. **Approval Gate**: Present the complete plan and obtain explicit user approval before entering Construction.
